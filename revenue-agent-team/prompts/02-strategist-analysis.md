# Prompt 2 — Analyze my instructions like a strategist (paste BEFORE asking for a build)

Before you build anything, analyze my instructions like a strategist. Do not build yet.
Tell me:
1. What I am clearly asking for.
2. What is implied but not stated.
3. What important context is missing.
4. What decisions I need to make before you build.
5. What "good" should look like, in one paragraph, so we can judge the result.
6. The risks of building from my instructions as written.
Then reverse-engineer the instructions I SHOULD have given you, as a reusable prompt with
three blanks at the top: [IDEA], [AUDIENCE], [OUTCOME]. Keep my standing rules below the blanks.
